## What is PubPub

PubPub is a **cross-platform Pub package browser** for searching, browsing and favoriting Dart / Flutter packages on [pub.dev](https://pub.dev). It runs on mobile (iOS / Android), desktop (Windows / macOS / Linux) and Web, and lets you switch freely between the official source and China mirrors.

## Highlights

- Multi-mirror search with debounce and pagination
- Package details: version list, dependency tree, README, copy install command
- Multiple favorite collections
- Responsive layout: mobile bottom nav, desktop fixed sidebar
- Local cache: tiered Hive cache + offline fallback
- Theming: system / light / dark + 10 theme colors
- i18n: 21 UI languages with RTL support (Arabic, Urdu, Persian)
