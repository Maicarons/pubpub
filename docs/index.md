## PubPub 是什么

PubPub 是一个**跨平台的 Pub 包浏览器**，用于搜索、浏览和收藏 [pub.dev](https://pub.dev) 上的 Dart / Flutter 包。它同时支持移动端（iOS / Android）与桌面端（Windows / macOS / Linux）以及 Web，并可在官方源与国内镜像源之间自由切换。

## 核心能力

- 多镜像源搜索，实时防抖、分页加载
- 包详情：版本列表、依赖树、README 展示、复制安装命令
- 多收藏夹分类管理
- 响应式布局：移动端底部导航，桌面端固定侧边栏
- 本地缓存：Hive 分级缓存 + 离线降级
- 主题：系统 / 亮 / 暗 + 10 种主题色
- 多语言：21 种界面语言，含阿拉伯语、乌尔都语、波斯语的 RTL 布局
